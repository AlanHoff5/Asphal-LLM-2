Large Language Model (LLM) — Modelo de Linguagem de Grande Escala: Rede neural profunda treinada sobre grandes volumes de texto para compreender e gerar linguagem natural. O "large" vale tanto para a quantidade de parâmetros quanto para o tamanho do corpus. É o objeto central do projeto: tudo que vem a seguir — Transformer, Attention, Pretraining, Fine-Tuning — existe para explicar como um LLM é construído. Fica no topo da hierarquia IA → Machine Learning → Deep Learning → LLM. O GPT-3, por exemplo, tem 175 bilhões de parâmetros.

Parameter / Weight — Parâmetro / Peso: Valor numérico ajustável da rede, otimizado durante o treinamento. É onde o conhecimento aprendido fica armazenado, e a contagem de parâmetros é a medida usual do tamanho de um modelo — está diretamente ligado ao conceito de Deep Learning, já que são os pesos das múltiplas camadas que dão à rede sua capacidade de representação. Uma camada linear de 768 para 768 já carrega quase 590 mil pesos.

Next-Word Prediction — Predição da Próxima Palavra: A tarefa de treinamento do GPT: prever o token seguinte dado todo o contexto anterior. É a tarefa concreta que implementa o Self-Supervised Learning e sustenta o Pretraining — é dela que emerge toda a capacidade linguística do modelo (ver Emergent Behavior). Dado "O café da manhã é a", o alvo é "refeição".

Self-Supervised Learning — Aprendizado Auto-Supervisionado: Paradigma em que os rótulos saem da própria estrutura dos dados, sem anotação humana. Como a próxima palavra do texto já é o rótulo, dá para treinar sobre corpora gigantescos sem rotular nada — é isso que torna o Pretraining viável em escala e o distingue do Fine-Tuning supervisionado tradicional (Classification Fine-Tuning), que depende de rótulos humanos.

Pretraining — Pré-Treinamento: Primeira fase do treinamento, feita sobre Raw Text não rotulado, para o modelo adquirir uma compreensão ampla da linguagem via Next-Word Prediction. Produz o Foundation Model, que depois será especializado por Fine-Tuning. É a etapa cara: estima-se que o pretraining do GPT-3 tenha custado US$ 4,6 milhões em créditos de nuvem.

Fine-Tuning — Ajuste Fino: Segunda fase, sobre um dataset menor e rotulado, especializando o modelo em uma Downstream Task ou domínio. Aproveita o que já foi aprendido no Pretraining, então custa bem menos, e é o mecanismo que transforma um Foundation Model genérico em algo utilizável. Divide-se em duas categorias principais: Instruction Fine-Tuning e Classification Fine-Tuning.

Instruction Fine-Tuning — Ajuste Fino por Instruções: Fine-tuning sobre pares de instrução e resposta. Transforma um modelo que só completa texto em um assistente que obedece comandos — foi assim que o ChatGPT nasceu a partir do GPT-3. Um exemplo de par: "Traduza para o alemão: bom dia" → "guten Morgen".

Classification Fine-Tuning — Ajuste Fino para Classificação: Fine-tuning sobre textos com rótulos de classe, normalmente trocando a camada de saída por uma cabeça de classificação. É o conteúdo do Capítulo 6, com o clássico exemplo de spam: ("Você ganhou um prêmio, clique aqui", spam).

Foundation Model / Base Model — Modelo de Fundação / Modelo Base: O modelo que sai do Pretraining, ainda genérico. Completa texto e já tem alguma capacidade de Few-Shot Learning, mas não segue instruções direito — só passa a fazer isso depois do Fine-Tuning. Serve como ponto de partida reutilizável para qualquer Downstream Task posterior. O GPT-3 antes do ajuste por instruções é o exemplo canônico.

Raw Text — Texto Bruto: Texto sem nenhuma informação de rotulagem. "Bruto" não quer dizer sem tratamento algum: filtragens como remover caracteres de formatação ou documentos em idiomas desconhecidos podem ter sido aplicadas. É a matéria-prima do Pretraining, consumida via Self-Supervised Learning.

Transformer — sem tradução consagrada, mantém-se o termo em inglês: Arquitetura apresentada no artigo "Attention Is All You Need" (2017), originalmente para tradução automática. Combina Encoder e Decoder ligados por mecanismos de Attention, e sustenta praticamente todos os LLMs modernos. Vale a ressalva do livro: nem todo transformer é LLM (existem para visão computacional) e nem todo LLM é transformer.

Encoder — Codificador: Submódulo que lê o texto de entrada e o converte em vetores numéricos carregados de contexto. Na tradução, é ele que codifica a frase da língua de origem para o Decoder consumir. O BERT é construído sobre ele; o GPT o descarta — é essa escolha arquitetural que separa as duas famílias de modelo.

Decoder — Decodificador: Submódulo que gera o texto de saída, um token por vez, da esquerda para a direita. É o único componente que o GPT mantém do transformer original, dando origem à Decoder-Only Architecture. Dado "Das ist ein", o decoder produz "Beispiel".

Decoder-Only Architecture — Arquitetura Somente-Decodificador: Variante do Transformer que fica só com a pilha de Decoders. Simplifica bastante a arquitetura e é suficiente para tarefas generativas via Next-Word Prediction. Define toda a família GPT, além do Llama, e é o que implementaremos no Capítulo 4.

Attention / Self-Attention — Mecanismo de Atenção / Auto-Atenção: Componente que calcula a importância relativa entre todos os tokens da sequência, deixando cada posição "consultar" as demais. É o que permite ao Transformer capturar dependências de longo alcance e dar acesso seletivo à entrada inteira durante a geração — sem ele, o Decoder não teria como relacionar tokens distantes entre si. Em "o animal não atravessou a rua porque ela era larga", a atenção é o que liga "ela" a "rua" e não a "animal". Núcleo da Sprint 3.

Embedding — Vetor de Representação (também "imersão"): Representação numérica densa de um Token, com cada dimensão capturando algum aspecto latente do significado. É o que converte texto discreto em entrada contínua para a rede, servindo de porta de entrada para o Transformer processar. O token "gato" vira, por exemplo, um vetor de 768 dimensões.

Token — unidade de texto, usa-se o termo em inglês: Unidade mínima de texto que o modelo lê — grosso modo, palavras e sinais de pontuação. Todo o processamento acontece nessa granularidade: é convertido em Embedding antes de entrar no modelo, e é sobre ele que a Next-Word Prediction opera. O GPT-3 foi treinado sobre 300 bilhões deles.

Autoregressive Model — Modelo Autoregressivo: Modelo que reaproveita as próprias saídas anteriores como entrada das predições seguintes. É como o GPT gera texto: cada palavra é escolhida com base em tudo que veio antes, o que dá coerência ao resultado — é a consequência direta de treinar via Next-Word Prediction. Gera "Das", realimenta, gera "ist", e assim por diante.

Emergent Behavior — Comportamento Emergente: Capacidade que o modelo demonstra sem ter sido treinado especificamente para ela. O GPT traduz entre idiomas mesmo tendo sido treinado só para prever a próxima palavra — algo que os pesquisadores não esperavam. Vem da escala (Parameters) e da diversidade do corpus de Pretraining, e é o que permite substituir vários modelos especializados por um só, incluindo Zero-Shot e Few-Shot Learning.

Zero-Shot Learning — Aprendizado sem Exemplos: Executar uma tarefa inédita sem nenhum exemplo prévio, só com a instrução. Manifestação direta do Emergent Behavior, e um dos motivos que tornam o Instruction Fine-Tuning tão eficaz depois. Ex.: pedir "Traduza para o alemão: breakfast =>" sem mostrar nada antes.

Few-Shot Learning — Aprendizado com Poucos Exemplos: Aprender a tarefa a partir de uns poucos exemplos colocados no próprio prompt, sem alterar um único Parameter do modelo. Melhora a precisão de graça, sem retreino, e é uma capacidade típica do Foundation Model mesmo antes de qualquer Fine-Tuning. Ex.: mostrar "gaot => goat" e "sheo => shoe" antes de perguntar "pohne =>".

Masked Word Prediction — Predição de Palavra Mascarada: Tarefa de treino em que palavras da frase são ocultadas e o modelo precisa reconstruí-las. É a estratégia do BERT — o contraponto direto da Next-Word Prediction usada pelo GPT — e rende representações bidirecionais boas para classificação. Ex.: "This is an __ of how concise I __ be".

BERT (Bidirectional Encoder Representations from Transformers) — Representações Bidirecionais de Codificadores a partir de Transformers: Família de LLMs construída sobre o Encoder do Transformer, treinada por Masked Word Prediction. Boa em classificação — análise de sentimento, categorização de documentos — justamente por não ser Decoder-Only. O X (antigo Twitter) usa BERT para detectar conteúdo tóxico. É o contraponto arquitetural do GPT.

GPT (Generative Pretrained Transformer) — Transformer Generativo Pré-Treinado: Família Decoder-Only apresentada por Radford et al. na OpenAI, voltada a tarefas generativas: completar texto, traduzir, resumir, escrever código. Passa pelas mesmas duas fases de qualquer LLM do livro — Pretraining seguido de Fine-Tuning — e é a arquitetura alvo do nosso projeto. O GPT-3 tem 96 camadas transformer, contra as 6 repetições do transformer original.

Downstream Task — Tarefa Subsequente: A tarefa específica para a qual um modelo pré-treinado é adaptado, geralmente bem diferente da tarefa usada no Pretraining (Next-Word Prediction). É o destino prático do Foundation Model: só depois do Fine-Tuning — por Instruction Fine-Tuning ou Classification Fine-Tuning — o modelo genérico vira útil para um problema real. A relação é direta e sequencial: Pretraining → Foundation Model → Fine-Tuning → Downstream Task. Exemplos: classificação de spam (Capítulo 6), resposta a perguntas médicas, sumarização de documentos jurídicos — em todos os casos, o mesmo Foundation Model poderia, em princípio, ser adaptado a qualquer uma dessas tarefas trocando apenas a etapa de fine-tuning.

Deep Learning — Aprendizado Profundo: Subcampo do Machine Learning baseado em redes neurais com três ou mais camadas ocultas ("deep" refere-se à profundidade da rede, não à qualidade do aprendizado). Sua função é dispensar a extração manual de features: num filtro de spam tradicional um especialista lista palavras-gatilho à mão, enquanto uma rede profunda descobre esses padrões sozinha a partir dos dados brutos. Posiciona-se na hierarquia IA → Machine Learning → Deep Learning → LLM apresentada no livro, e é a base técnica que torna os LLMs viáveis: um LLM é, em essência, uma aplicação de Deep Learning para texto, usando o Transformer como espinha dorsal e o Embedding como forma de representar a entrada. Exemplo: mesmo o GPT-2 pequeno (117M/125M parâmetros) já opera com 768 dimensões de Embedding por camada — uma capacidade de representação muito além do que um modelo raso (poucas camadas) conseguiria capturar.

PyTorch: Biblioteca de Deep Learning usada na maioria das implementações de LLM hoje, e a que o livro adota. Fornece tensores, autograd, camadas prontas e suporte a GPU. É o meio pelo qual os conceitos da Parte 1 (Embedding, Attention, Decoder) serão efetivamente codificados nas próximas sprints — não define nenhum conceito teórico novo, mas é o instrumento de tradução entre teoria e código. Toda a implementação do projeto sai daqui: torch.nn.Linear(768, 768), por exemplo, cria uma das camadas densas do bloco transformer.
